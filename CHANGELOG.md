# Changelog

All notable changes to Node Glue are documented here.

## [0.1.0] - 2026-09-02

### Added

- Verified immutable package storage.
- Project-specific dependency materialization through managed links.
- npm lockfile v2 and v3 input support.
- Registry, local directory, Git, and HTTP(S) tarball sources.
- `install`, `ensure`, `exec`, `doctor`, `gc`, `enable`, and `disable` CLI commands.
- Opt-in npm and npx integration.
- Read-only diagnostics, rollback handling, and reference-preserving garbage collection.
